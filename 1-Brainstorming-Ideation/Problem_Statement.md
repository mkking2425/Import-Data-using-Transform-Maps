# Problem Statement

## Project Title: Import Data using Transform Maps

### 1. Current Scenario
The HR department maintains employee records in Excel spreadsheets (e.g., Banking Employees data). Currently, all employee details like Employee ID, Name, Email, Department, and Location are stored manually in Excel files.

### 2. Problem Identified
- Manual data entry into ServiceNow is extremely time-consuming. Entering 15 records takes 1 hour, so 1500 records would take 4-5 days.
- High chance of human errors like spelling mistakes and incorrect email IDs.
- Duplicate records are created when the same Employee ID is entered multiple times.
- No efficient way to track which data is new and which is already existing.

### 3. Need for Solution
We need an automated system to import bulk data from Excel/Spreadsheet directly into the ServiceNow target table (u_employee_test) to save time, avoid duplicates, and ensure data accuracy.
