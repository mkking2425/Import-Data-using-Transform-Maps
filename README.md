# Import Data using Transform Maps - ServiceNow Project

**Student Name:** Manikandan M
**Project Domain:** ServiceNow Development

### Project Description
This project automates bulk employee data import from Excel to ServiceNow using Import Sets and Transform Maps with Coalesce to prevent duplicates.

### Key Features
- Bulk import of 15+ records in seconds
- Duplicate prevention using Coalesce on Employee ID
- Auto Map for 5 fields
- Reports and Dashboard

### How to Run
1. Create u_employee_test table
2. Load Sample Spreadsheet.xlsx via Import Sets
3. Use Transform Map "Sample Spreadsheet Import" to Transform
